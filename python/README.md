# latticeag-herald (Python)

Python library for the Herald sovereign agent identity registry: strict JSON,
RFC 8785 canonicalization, tagged digests, strict Ed25519, the offline
`verify`/`verify_history` functions, the HTTP client wrappers, and the
normative conformance fixture generator (`python -m latticeag_herald.fixtures`).

See the repository root README for the protocol profile and security model.
